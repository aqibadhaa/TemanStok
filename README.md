# TemanStok 📦
> Sistem Manajemen Stok Warung Kelontong Berbasis Voice AI dan Agen Cerdas Proaktif untuk UMKM Indonesia

---

## Tentang Aplikasi

TemanStok adalah aplikasi mobile Android yang dirancang khusus untuk warung, toko kelontong, dan UMKM retail kecil. Dengan menggabungkan **input suara**, **kecerdasan buatan**, dan **notifikasi WhatsApp otomatis**, pemilik warung dapat mencatat transaksi, memantau stok, dan mendapatkan rekomendasi bisnis — hanya dengan berbicara.

---

## Keunggulan Utama

-  **Multi-Item Voice Transaction** — Catat hingga 3 produk sekaligus dalam 1 ucapan natural, contoh: *"Pocari terjual 1, Kopi ABC terjual 1, Milo keluar 2"*
-  **4 Agen AI Proaktif** — Rekap harian, insight mingguan, rencana kulaan, dan pengingat kedaluwarsa dikirim otomatis ke WhatsApp tanpa perlu membuka aplikasi
-  **Notifikasi via WhatsApp** — Menggunakan aplikasi yang sudah familiar di kalangan UMKM Indonesia
-  **Autentikasi OTP Aman** — OTP diproses sepenuhnya di backend dengan kebijakan keamanan: expiry 5 menit, maksimal 5x percobaan, cooldown 59 detik
-  **Backend 24/7** — n8n di-host di VPS Hostinger Jakarta, semua agen terjadwal berjalan tanpa ketergantungan pada perangkat pengembang

---

## Instalasi

1. Download file TemanStok.apk yang tersedia.
2. Pada link Drive, double tap pada “TemanStok.apk” kemudian bisa pilih Install without scanning atau juga bisa pilih Install with scanning.
3. Setelah instalasi selesai, tap **"Buka"** atau **"Open"**
4. Izinkan akses **mikrofon** saat diminta, diperlukan untuk fitur pencatatan via suara
5. Daftar menggunakan nomor WhatsApp aktif dan ikuti proses onboarding
6. Setelah berhasil masuk ke aplikasi, **segera menuju laman Home dan lakukan REFRESH.**

> ⚠️ **Catatan:** Setelah berhasil masuk melalui **Daftar Baru**, disarankan untuk me-refresh aplikasi dengan cara **scroll ke bawah pada halaman Home** agar data inventori tampil dengan benar.
